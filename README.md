# Dolibarr-conteopermanente

## Módulo de conteo permanente para Dolibarr

Este módulo permite hacer conteo utilizando la cámara de un dispositivo móvil para escanear las etiquetas o registrar manualmente la información de descripción, cantidad y precio del artículo.

También genera un archivo en pdf o csv con la información (en proceso).

Si el usuario tiene perfil administrador le permite visualizar los conteos previos.
